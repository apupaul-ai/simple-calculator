# Simple Calculator

A command-line calculator built in Python as a daily practice project. Started as a basic 4-operation calculator and evolved day by day into a full-featured tool with error handling, advanced math operations, functions, and calculation history.

## Features

- **Basic Operations:** Addition, Subtraction, Multiplication, Division
- **Advanced Operations:** Power, Square Root, Modulus
- **Repeat Mode:** Keep calculating without restarting the program
- **Error Handling:** Gracefully handles invalid input (e.g. text instead of numbers) and division/modulus by zero
- **Calculation History:** View a log of all calculations performed in the session
- **Clean Code Structure:** Each operation is a separate function for readability and reusability

## How to Run

```bash
python calculator.py
```

Follow the on-screen menu to choose an operation, enter numbers, and view results.

## Menu Options

```
1. Add (+)
2. Subtract (-)
3. Multiply (*)
4. Divide (/)
5. Power (^)
6. Square Root (√)
7. Modulus (%)
8. Show History
```

## Example

```
Choose operation (1-8): 1
Enter first number: 10
Enter second number: 5
Result: 15.0
```

## Built With

- Python 3
- Core concepts used: variables, type conversion, loops, conditionals, functions, try/except, lists
